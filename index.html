Companion to Efficient Exploration in Model-Based RL

1. Roadmap: What Are We Proving and Why?

Big Picture

The paper describes a method for teaching a computer agent to make good decisions by learning how the world works. The agent doesn't know the rules of the world (the "transition dynamics") and has to figure them out from experience, while also making good decisions along the way.

The central tension is the exploration–exploitation tradeoff: the agent must sometimes try new things (explore) to learn, even though sticking with what it already knows (exploit) would give better immediate results.

The paper's key trick is to use a special mathematical reformulation that makes the learning problem convex — meaning there's a single "best answer" with no confusing local traps. This convexity has three important consequences:

  1. We can find the best model parameters reliably (no local minima).
  2. We can sample random models from a well-behaved probability distribution (for exploration).
  3. We can prove that the agent's total "regret" grows slowly.

The paper contains three main theoretical results:

  1. Proof 1 — Convex Reformulation (Theorem 3.1): A neural network training problem — which is normally non-convex and hard — can be rewritten as a convex problem in a higher-dimensional space.
  2. Proof 2 — MYULA Convergence (Theorem 3.3): A sampling algorithm (MYULA) can efficiently draw random samples from the posterior distribution, with a guaranteed accuracy.
  3. Proof 3 — Bayesian Regret Bound (Theorem 3.5): The agent's total regret over $N$ episodes grows as $\tilde{O}(H^{3/2}\sqrt{PdT})$, which is sublinear in the total number of steps $T$.

2. Mathematical Background

Vectors & Norms

Definition — Euclidean Norm

The Euclidean norm (or $\ell_2$ norm) of a vector $\mathbf{v} \in \mathbb{R}^d$ is:

$$\|\mathbf{v}\| = \sqrt{v_1^2 + v_2^2 + \cdots + v_d^2}$$

This measures the "length" of the vector.

Example
  • $\mathbf{v} = (3, 4)$: $\|\mathbf{v}\| = \sqrt{9+16} = 5$ (a 3-4-5 right triangle).
  • $\mathbf{v} = (1,1,1)$: $\|\mathbf{v}\| = \sqrt{3} \approx 1.73$.
  • $\mathbf{v} = (0,0,0)$: $\|\mathbf{v}\| = 0$ (only the zero vector has norm zero).
Definition — Group LASSO Norm

If $\mathbf{z} \in \mathbb{R}^{2Pd}$ is partitioned into $2P$ blocks of size $d$, then:

$$g(\mathbf{z}) = \beta \sum_{j=1}^{2P} \|\mathbf{z}_j\|_2$$

This encourages entire blocks to be zero ("group sparsity").

Matrices & Eigenvalues

Definition — Weighted Norms

Given a positive definite matrix $H$, the $H$-norm is $\|\mathbf{v}\|_H = \sqrt{\mathbf{v}^\top H \mathbf{v}}$. This stretches or compresses directions according to $H$.

In the paper, the $H_k^{-1}$-norm measures uncertainty: directions where the agent has little data get large norm (high uncertainty), encouraging exploration there.

Eigenvalue ratio $\lambda_1/\lambda_2$: 4.0
Interactive: Drag the slider to change the eigenvalue ratio. Left: standard norm (always a circle). Right: $H$-norm (becomes more elliptical as the ratio grows). The short axis = certain direction; the long axis = uncertain direction.

Convexity

Definition — Convex Function

A function $f$ is convex if the line segment between any two points on its graph lies above the graph:

$$f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y) \quad \text{for all } \lambda \in [0,1]$$
Convex vs. non-convex. Left: $f(x)=x^2$. The chord (red dashed) always lies above the curve — gradient descent finds the global minimum. Right: $f(x)=x^4-2x^2$. The chord dips below — multiple local minima where gradient descent can get stuck.
Definition — Strong Convexity & Smoothness

$f$ is $\mu$-strongly convex if $f(y) \geq f(x) + \nabla f(x)^\top(y-x) + \frac{\mu}{2}\|y-x\|^2$. It is $L$-smooth if $\|\nabla f(x) - \nabla f(y)\| \leq L\|x-y\|$.

The condition number $\kappa = L/\mu$ controls how elongated the contours are. $\kappa = 1$: circular (easy). $\kappa \gg 1$: elongated (hard).

Condition number $\kappa$: 1.0
Interactive: Drag the slider to increase $\kappa$. Circular contours ($\kappa=1$) become elongated ellipses, making gradient descent zig-zag.

Probability Distributions

Definition — Log-Concave Distribution

A distribution with density $p(\mathbf{z}) \propto \exp(-U(\mathbf{z}))$ is log-concave if $U$ is convex, and strongly log-concave if $U$ is strongly convex. Gaussians are the canonical example.

Log-concave vs. multimodal. Left: Three log-concave distributions (Gaussian, Laplace, elastic net) — each has a single peak. Right: A mixture of two Gaussians is not log-concave (the dip between peaks means $U = -\log p$ is non-convex).
Definition — Total Variation Distance

For distributions $p$ and $q$: $\mathrm{TV}(p,q) = \frac{1}{2}\int |p(z) - q(z)|\,dz$. It measures the largest difference in probability assigned to any event.

Shift $\delta$: 1.5
Interactive: Drag the slider to shift $q$ away from $p$. The shaded area is $|p(z)-q(z)|$; TV $= \frac12$ × (shaded area). When $\delta=0$ the distributions are identical (TV$=0$).

Proximal Operators

Definition — Proximal Operator

For a convex function $g$ and parameter $\lambda > 0$:

$$\mathrm{prox}_{\lambda g}(\mathbf{z}) = \arg\min_{\mathbf{u}} \left\{g(\mathbf{u}) + \frac{1}{2\lambda}\|\mathbf{z}-\mathbf{u}\|^2\right\}$$

For $g(z)=|z|$, this is soft thresholding: $\mathrm{prox}_g(z) = \mathrm{sign}(z)\max(|z|-\lambda\beta,\, 0)$.

Threshold $\lambda\beta$: 1.0
Interactive: Adjust the threshold. Inputs within the dead zone (red) are snapped to zero; inputs outside are shrunk toward zero by $\lambda\beta$.

3. Proof 1: Convex Reformulation (Theorem 3.1)

Big Picture

Goal: Show that training a two-layer ReLU neural network with regularisation is equivalent to solving a convex optimisation problem in a higher-dimensional space.

Why it matters: Neural network training is usually non-convex (many local minima, no guarantees). If we can reformulate it as a convex problem, we get a unique global solution, and — crucially — the resulting posterior distribution is log-concave.

The Non-Convex Starting Point

Given inputs $X \in \mathbb{R}^{n \times d}$ and targets $y \in \mathbb{R}^n$, the training problem is:

$$\min_{\{\mathbf{w}_j, \alpha_j\}} \frac{1}{2n}\sum_{i=1}^n \left(y_i - \sum_{j=1}^m \alpha_j [\mathbf{w}_j^\top x_i]_+\right)^2 + \frac{\beta}{2}\sum_{j=1}^m (\|\mathbf{w}_j\|^2 + \alpha_j^2)$$
Watch Out

This problem is non-convex because of the product $\alpha_j [\mathbf{w}_j^\top x_i]_+$. When you multiply two unknowns, the function can have multiple local minima.

Step 1: Absorbing the Bilinear Coupling (AM-GM Trick)

The AM-GM inequality gives $\frac{1}{2}(\|\mathbf{w}\|^2 + \alpha^2) \geq \|\mathbf{w}\|\cdot|\alpha|$ with equality when $\|\mathbf{w}\| = |\alpha|$.

Define $\mathbf{v}_j := \alpha_j \mathbf{w}_j$. The data-fit becomes linear in $\mathbf{v}_j$, and the regulariser becomes the convex group norm $\|\mathbf{v}_j\|_2$.

Key Idea

The substitution $\mathbf{v}_j = \alpha_j \mathbf{w}_j$ absorbs the bilinear product into a single vector. This is the step that converts a non-convex problem into a convex one.

Step 2: From Semi-Infinite to Finite Program

The number of possible activation patterns can be exponential, giving a semi-infinite program. Conic duality (Lagrangian relaxation) handles the infinitely many constraints, and in practice we fix $P$ random sign patterns at initialisation.

Step 3: Variable Lifting

Stack all $2P$ blocks into $\mathbf{z} \in \mathbb{R}^{2Pd}$ to get the group LASSO:

$$\min_{\mathbf{z} \in \mathbb{R}^{2Pd}} \frac{1}{2n}\|\tilde{X}\mathbf{z} - y\|^2 + \beta \sum_{j=1}^{2P} \|\mathbf{z}_j\|_2$$
The convex reformulation pipeline. A non-convex neural network (left) is transformed into a convex group LASSO (right) via the AM-GM substitution and pattern fixing. Animation shows the transformation step by step.
Checkpoint

Training a two-layer ReLU network with $\ell_2$ regularisation is equivalent to solving the group LASSO. The non-convexity has been completely eliminated by moving to a higher-dimensional space. ◻

4. Interlude: The Log-Concave Posterior

With the convex reformulation in hand, the posterior is:

$$\pi(\mathbf{z} \mid \mathcal{D}) \propto \exp\!\left(-\underbrace{\frac{1}{2\sigma^2}\|\tilde{X}\mathbf{z}-y\|^2 - \frac{1}{2\sigma_0^2}\|\mathbf{z}\|^2}_{f(\mathbf{z})\text{ — smooth, strongly convex}} - \underbrace{\beta\sum_j \|\mathbf{z}_j\|_2}_{g(\mathbf{z})\text{ — convex, non-smooth}}\right)$$

Since $U(\mathbf{z}) = f(\mathbf{z}) + g(\mathbf{z})$ is the sum of two convex functions, it is convex, making $\pi$ log-concave. Moreover, $f$ is strongly convex (thanks to the elastic-net prior), so $\pi$ is strongly log-concave.

Key Idea

Log-concavity = single mode = Langevin dynamics mix fast = efficient sampling = controlled exploration. The entire paper's exploration machinery rests on this one property.

5. Proof 2: MYULA Convergence (Theorem 3.3)

Big Picture

Goal: Show that the MYULA algorithm can produce a sample that is within total variation distance $\varepsilon$ of the true posterior in $\tilde{O}(D\kappa_\lambda^2/\varepsilon^2)$ iterations.

Challenge: The posterior has a non-smooth part $g$ (the group LASSO penalty), so standard Langevin dynamics can't directly apply — the gradient of $g$ doesn't exist everywhere.

What Is Langevin Dynamics?

Prerequisites

Continuous-time Langevin: $d\mathbf{z}_t = -\nabla U(\mathbf{z}_t)\,dt + \sqrt{2}\,d\mathbf{B}_t$

Discrete-time (ULA): $\mathbf{z}_{k+1} = \mathbf{z}_k - \eta \nabla U(\mathbf{z}_k) + \sqrt{2\eta}\,\boldsymbol{\xi}_k$, where $\boldsymbol{\xi}_k \sim \mathcal{N}(\mathbf{0}, I)$.

The gradient $-\nabla U$ pulls the particle toward high-probability regions; the noise lets it explore.

Langevin dynamics. A particle (red dot) starts far from the mode and is pulled toward the peak by the gradient. Random noise prevents it from sitting at the peak and lets it explore the width of the distribution.

The Proof Strategy: Three Error Sources

The total sampling error decomposes as:

$$\mathrm{TV}(\nu_K, \pi) \leq \underbrace{\mathrm{TV}(\nu_K, \pi_\lambda)}_{\text{sampling error from }\pi_\lambda} + \underbrace{\mathrm{TV}(\pi_\lambda, \pi)}_{\text{smoothing bias}}$$

We split the error budget $\varepsilon$ into three equal parts of $\varepsilon/3$ each.

The three error sources in MYULA. Initialisation decays exponentially with steps $K$. Discretisation shrinks with smaller step size $\eta$. Smoothing bias shrinks with smaller $\lambda$.

Lemma 1: Moreau–Yosida Smoothing

Definition — Moreau Envelope

$M_\lambda g(\mathbf{z}) = \inf_{\mathbf{u}} \left\{g(\mathbf{u}) + \frac{1}{2\lambda}\|\mathbf{z} - \mathbf{u}\|^2\right\}$

Near the origin, the sharp V-shape of $|z|$ is replaced by a smooth parabola. The gradient becomes continuous everywhere.

Smoothing $\lambda$: 1.0
Interactive: Adjust $\lambda$ to see how the Moreau envelope (blue) smooths the non-differentiable $|z|$ (red dashed). Larger $\lambda$ = more smoothing but larger approximation gap $\delta$.

Lemma 2: ULA Convergence for Smooth Targets

Once the target is smooth (via Moreau), ULA converges exponentially fast thanks to the log-Sobolev inequality (LSI) from strong convexity. The KL divergence contracts as $\mathrm{KL}(\nu_k \| \pi_\lambda) \leq e^{-2\mu\eta k}\,\mathrm{KL}(\nu_0 \| \pi_\lambda) + O(D\eta L^2/\mu)$.

Lemma 3: Smoothing Bias

$\mathrm{TV}(\pi_\lambda, \pi) \leq \lambda L_g^2/2$. Smaller $\lambda$ reduces bias but increases the smoothed Lipschitz constant $L = L_f + 1/\lambda$.

Checkpoint

MYULA produces samples within TV distance $\varepsilon$ of the true posterior in $\tilde{O}(D\kappa_\lambda^2/\varepsilon^2)$ iterations. Key ingredients: (1) Moreau smoothing (needs convexity for well-behaved prox), (2) LSI from strong convexity, (3) careful three-way error balancing. ◻

6. Proof 3: Bayesian Regret Bound (Theorem 3.5)

Big Picture

Goal: Show that total regret $\leq \tilde{O}(R_{\max} H^{3/2}\sqrt{PdT})$. The regret grows as $\sqrt{T}$, much slower than $T$ (linear) — the agent learns.

Sublinear regret means the agent learns. Linear (red): no improvement. Our $\tilde{O}(\sqrt{T})$ bound (blue): average regret per step $\to 0$. Logarithmic (green): ideal for simpler settings.

Lemma A: The Simulation Lemma

Lemma (Simulation)

The difference in value between two models decomposes into a sum of per-step Bellman errors:

$$V_0^\pi(\hat{P}) - V_0^\pi(P^\star) = \sum_{h=0}^{H-1} \mathbb{E}\!\left[(\hat{P} - P^\star)V_{h+1}^{\pi,\hat{P}}(s_h, a_h)\right]$$
The simulation lemma. The true model $P^\star$ (blue, top) and estimated model $\hat{P}$ (red, bottom) diverge at each step. The total value difference telescopes into per-step Bellman errors $e_h$ (orange).

Lemma B: Eluder Dimension

Because the sign patterns are fixed, the function class $\mathcal{F}_P$ is linear in the lifted parameters $\mathbf{z}$. Therefore:

  • Eluder dimension: $\tilde{O}(Pd)$ — you need about $Pd$ informative observations.
  • Covering number: $\log \mathcal{N}(\mathcal{F}_P, \varepsilon) = O(Pd\log(BR_\phi/\varepsilon))$.
Key Idea

This is where the convex reformulation is critical. In a standard neural network, the function depends nonlinearly on the weights. Here, because we've fixed the sign patterns, the dependence on $\mathbf{z}$ is linear, making $\mathcal{F}_P$ a $2Pd$-dimensional linear class with small eluder dimension.

Lemma C: PSRL Regret via Hellinger Geometry

This is the heart of the regret analysis. The proof chains: Simulation Lemma → Hellinger contraction → Cauchy–Schwarz → Elliptic Potential Lemma.

Proof sketch (click to expand)

Step 1 — Posterior Sampling Identity: $\mathbb{E}[\Delta_n \mid \mathcal{D}_{n-1}] = \mathbb{E}[V_0^{\pi_n}(\hat{P}_n) - V_0^{\pi_n}(P^\star)]$.

Step 2 — Apply Simulation Lemma: Decompose into $H$ Bellman errors, each bounded by $HR_{\max}\cdot\mathrm{TV}(\hat{P}_n, P^\star)$.

Step 3 — Hellinger Contraction: Under Gaussian noise, $\mathrm{Hel}^2 \leq \|\hat{f}_n(x) - f^\star(x)\|^2/(8\sigma_\varepsilon^2)$, converting "how different are the distributions?" into "how different are the predictions?".

Step 4 — Cauchy–Schwarz: $\sum_{n,h} \|e_{n,h}\| \leq \sqrt{T \sum_{n,h} \|e_{n,h}\|^2}$.

Step 5 — Elliptic Potential: Because $\mathcal{F}_P$ is linear, cumulative squared prediction errors are bounded: $\sum_{n,h}\|\hat{f}_n(x_{n,h}) - f^\star(x_{n,h})\|^2 \leq d_{\mathrm{ms}} = \tilde{O}(HPd)$.

Result: $\mathrm{Regret}_N^{\mathrm{exact}} = \tilde{O}(R_{\max} H^{3/2}\sqrt{PdT})$.

Lemma D: Approximate Sampling Error

MYULA gives an approximation, not an exact sample. A coupling argument bounds the cost:

The coupling argument. Exact and approximate samples are coupled so they agree with probability $\geq 1-\varepsilon_{\mathrm{samp}}$. Extra regret per episode $\leq HR_{\max}\cdot\varepsilon_{\mathrm{samp}}$.

Assembling the Final Bound

How the four lemmas assemble. Lemma A + B feed into Lemma C (exact regret). Lemma D (using MYULA from Proof 2) adds the approximate-sampling correction. Together: $\tilde{O}(R_{\max}H^{3/2}\sqrt{PdT})$.
Checkpoint

Where convexity is used: (1) Eluder dimension — linear class ⇒ $\tilde{O}(Pd)$. (2) Elliptic potential — precision matrix $H_k$ bounds cumulative errors. (3) Sampling — log-concavity ⇒ MYULA mixes in poly time. Without the convex reformulation, all three steps break. ◻

7. Summary: The Logical Chain

  1. Non-convex neural network $\xrightarrow{\text{Pilanci–Ergen}}$ Convex group LASSO in $\mathbb{R}^{2Pd}$
    (Proof 1: variable substitution + duality + lifting)
  2. Convex group LASSO + elastic-net prior ⇒ Log-concave posterior $\pi \propto \exp(-U)$
    (Proposition 3.2: sum of convex functions is convex)
  3. Log-concave posterior + Moreau smoothing ⇒ MYULA samples with $\mathrm{TV} \leq \varepsilon$ in poly time
    (Proof 2: Bakry–Émery LSI + ULA convergence + smoothing bias)
  4. Linear function class ⇒ Eluder dimension $\tilde{O}(Pd)$
    (Lemma B: covering numbers for linear classes)
  5. Simulation + Hellinger + Cauchy–Schwarz + Elliptic potential ⇒ $\mathrm{Regret}^{\mathrm{exact}} = \tilde{O}(H^{3/2}\sqrt{PdT})$
    (Lemma C: the main regret calculation)
  6. Exact regret + coupling for approximate sampling ⇒ Final bound $\tilde{O}(R_{\max} H^{3/2}\sqrt{PdT})$
    (Lemma D + parameter choice $\varepsilon_{\mathrm{samp}} = 1/\sqrt{N}$)

The $H^{3/2}$ factor: One factor of $H$ comes from $\|V\|_\infty \leq HR_{\max}$. The extra $\sqrt{H}$ comes from per-episode (not per-step) posterior updates, giving $d_{\mathrm{ms}} = \tilde{O}(HPd)$.
